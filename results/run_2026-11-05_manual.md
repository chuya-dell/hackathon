# 通しの実行(2026-11-05、手動版)

## これは何か
`claude -p` が Yoga で認証に失敗したため、道具 `saihatsu` 本体は動かせなかった。同じ手順を、Claude Code のセッションが次のように代行した。**道具の自動の実行ではない。**

- extract / add:セッションの Claude が、`core.py` の指示文の趣旨に沿って手で行った(`extract_0N.json`、`rules.md`)。5本の規則は互いに別の行動なので重複はなく、発生回数はすべて 1。
- check の出し直し:規則なし・規則あり(5規則すべてを貼った `export.md` と同じ内容)を、10個の独立したサブエージェント(モデル sonnet)に1つずつ出した。会話履歴は、どの例も苛立ちの直前の依頼(最初の利用者の発言)のみ。
- 判定:別の呼び出しではなく、セッションの Claude が1人で行った(判定役が規則の作者と同じなので、甘くなる恐れがある)。

## 読み取り(確度:高)
差は出なかった。理由は、examples の「誤り」が**架空の AI の誤り**であり、今のモデルは規則なしでもその誤りをほとんど起こさないため。前後比較は「規則なしで誤りが再現する」ことが前提なので、この5本では効果を示せない。

次の手:デモでは、実際に再発する誤りを使う。例えば、(a) 長い制約付きの依頼で後半の制約が落ちる、(b) 白石が実際に何度も受けた誤りを、**架空の言い回しに直して**会話にする、(c) 弱いモデル(`haiku`)で規則なしの再発率を上げる、のいずれか。
