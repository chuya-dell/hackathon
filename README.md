# AFM 断面図アプリ(原子間力顕微鏡の像を、装置なしで自分のパソコンで解析する)

研究室のメンバーが、原子間力顕微鏡(日立ハイテクサイエンス AFM5000Ⅱ)で撮った像を、**装置にも付属アプリにも並ばずに**、自分のパソコンのブラウザで解析するためのアプリです。HTML のファイルを1つダブルクリックするだけで動きます。インストールもインターネットも要らず、画像のデータはパソコンの外へ送られません。

Built with Claude: Japan 2026 の提出作品です。Claude Code で作りました。

## 解く不便

原子間力顕微鏡の像の解析は、装置の横のパソコンにある付属アプリ(NanoNaviApp)で行う必要がありました。ピラー(基板の上の柱)の高さを1つ測るにも、そのパソコンの前に行き、付属アプリの操作を覚える必要がありました。

このアプリは、測った像のファイル(.xqd)か、数値の表を枠に入れるだけで、断面図・高さ・距離をその場で出します。

## 2つの版

| ファイル | 内容 |
|---|---|
| `afm_simple.html` | **簡易版(ふだん使う方)**。画像の上に線を引くと、線に沿った断面図が出る。断面図の上で区間をドラッグすると、高さ(点2 − 点1)と距離が大きく出る。傾き補正(一次・二次・三次)をボタンで重ねられる。三次元表示もできる。使い方は `使い方_簡易版.txt`。 |
| `afm_analyzer.html` | 多機能版。傾き補正、表面粗さ、ピラーの高さ(2つの方法)、ピラーの個数と中心間の間隔、三次元表示、結果の CSV 書き出し。使い方と計算の定義は `README_多機能版.md`。 |

## 試し方

1. このリポジトリを取得する(右上の「Code」→「Download ZIP」でもよい)。
2. `afm_simple.html` をダブルクリックする(Chrome か Edge)。
3. `tests/data/synthetic_square_30um.csv` を、上の左の枠へドラッグする。走査範囲を **30**(マイクロメートル)に直す。
4. 「二次」を押して傾きを引き、画像の上でピラーを横切る線を引く。断面図の上で、床からピラーの頂上までドラッグすると、高さが約 250 ナノメートルと出る。

## 計算の確かめ方

合成データ(高さ 250 ナノメートルの円柱ピラーを並べ、既知の傾き・湾曲・雑音を足した像)で、計算が正しいかを確かめています。

```bash
cd tests
node run_tests.js          # Node.js が必要。結果は 結果_計算の確認.md
python make_synthetic.py   # 合成データを作り直す場合(Python と numpy が必要)
```

結果: **42 項目すべて合格**(ピラーの高さは真の値 250 ナノメートルから ±2 ナノメートル以内、個数は 100 個ちょうど、など)。

## 注意

- .xqd の直接読み込みは、ファイルの形式を Claude と調べて作った実験的な機能です。**高さの倍率は未確定**で、画面に赤字で出ます。確実な方法は、付属アプリで数値の表を書き出して読み込む方法です。
- 公開しているのは、アプリ本体と、合成データでの試験だけです。実際の測定データと、それを使った画面確認・形式の調査のスクリプトは、研究データを含むため入れていません(`README_多機能版.md` に出てくる `gui_check.js`、`xqd_調査.py` などは、このリポジトリにはありません)。
- 外部のライブラリは使っていません(三次元表示も自前の描画です)。
