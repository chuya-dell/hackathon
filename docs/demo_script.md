# デモ動画の台本(3分、画面録画、白石が読み上げる)

事前準備: Claude Code にログイン済み(`claude auth status` で確認)。デモでは時間短縮のため `--model haiku` を付けてもよい(コマンドの先頭の `saihatsu` の直後に書く)。`out3.json` は事前に `extract` で作っておいてもよい。作業フォルダに `rules.md` がない状態から始める。端末の文字を大きくしておく。`examples/01_…md` の中身をエディタに開いておく。

## 0:00〜0:30 不便の提示
**画面:** `examples/01_例を中心にしてしまう.md` をエディタで見せる。

**読み上げ:** 「人工知能に『たとえば“ゆるい”感じで』と頼むと、案が全部『ゆる』から始まります。私が挙げたのは例なのに、中心にされてしまう。こういう誤りを、毎日のように繰り返されます。注意を書き足しても、それが効いているのか、私には分かりません。そこで作ったのが『再発防止帳』です。」

## 0:30〜1:30 extract と add で規則帳が育つ
**画面と打つコマンド:**

```bash
saihatsu extract examples/01_例を中心にしてしまう.md -o out1.json
saihatsu add out1.json --rules rules.md
saihatsu extract examples/04_返答が長すぎる.md -o out4.json
saihatsu add out4.json --rules rules.md
saihatsu extract examples/02_頼んでいない作業を始める.md -o out2.json
saihatsu add out2.json --rules rules.md
```

**読み上げ:** 「会話記録から、私が苛立った場面と、その直前の人工知能の誤りを取り出します。誤りの種類、原因、そして、守ったかどうか後から判定できる1行の規則が付きます。これを規則帳に足します。違う会話を足すと、規則が増えていきます。」
続けて、意味の重なる会話を足す場面:

```bash
saihatsu extract examples/03_確かめずに断定する.md -o out3.json
saihatsu add out3.json --rules rules.md
```

**読み上げ:** 「似た規則は足されず、『発生回数』が1増えます。規則帳が、重複なく育ちます。」`rules.md` をエディタで開いて見せる。

## 1:30〜2:30 check の前後比較
**画面と打つコマンド:**

```bash
saihatsu check examples/03_確かめずに断定する.md --rules rules.md --extraction out3.json --repeat 3
```

**読み上げ:** 「ここがこの作品の芯です。苛立つ直前の私の依頼を、規則なしと規則ありの2通りで、人工知能に出し直します。別の呼び出しで、同じ誤りが再発したかを判定し、表にします。同じ依頼を3回ずつ出し直すと、規則なしでは「確かめずに断定する」誤りが再発し、規則ありでは再発しません。規則が効いたことが、数字で分かります。記憶は覚えるだけです。再発防止帳は、効いたかどうかまで確かめます。」表の「規則なし」「規則あり」の列を指す。

## 2:30〜3:00 まとめ
**画面と打つコマンド:**

```bash
saihatsu export --rules rules.md
```

**読み上げ:** 「規則帳は、そのまま CLAUDE.md や会話の冒頭に貼れる形で出せます。誤りを取り出し、規則にし、効いたかを確かめる。人工知能の同じ誤りに、日々うんざりしてきた私が、諦めずに済む道具を作りました。ありがとうございました。」
