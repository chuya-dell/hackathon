# 提出用のプロジェクト概要(約400字)

**再発防止帳(saihatsu-boushi)** は、人工知能に同じ誤りを繰り返される不便を解く道具です。「例として挙げただけなのに案が全部その例になる」「頼んでいない作業を始める」「確かめずに断定する」。こうした誤りは、そのたびに注意を書き直しても、効いたのか分からないまま繰り返されます(テーマ1:諦めてきた日々の不便)。

会話記録から、利用者が苛立った場面と、その直前の人工知能の誤りを Claude が組で取り出し、誤りの種類・原因・「守ったかを後から判定できる1行の規則」を付けます。規則は1つの md ファイル(規則帳)に足され、意味が重なるものは発生回数を増やすだけで、重複なく溜まります。

核は前後比較です。苛立つ直前の依頼を、規則なし・規則ありの2通りで Claude に出し直し、別の呼び出しで同じ誤りが再発したかを判定し、表にします。規則が効いたかを数字で示す点が、覚えるだけの記憶機能との違いです。規則帳は CLAUDE.md や会話の冒頭にそのまま貼れます。Claude Code を内部で呼ぶ Python 製のコマンド1つ(API キー不要)(extract / add / check / export)で、公開できる架空の会話5本で動作を確認できます。
